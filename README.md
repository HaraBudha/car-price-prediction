# 🚗 Car Price Prediction using Machine Learning

## 📌 Project Overview
This project predicts car selling prices using a Linear Regression model.
The dataset includes features like year, present price, driven kilometers,
fuel type, transmission type, and owner details.

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 📊 Project Steps
1. Data Loading
2. Data Preprocessing
3. Feature Encoding
4. Train-Test Split
5. Model Training (Linear Regression)
6. Model Evaluation (R2, MAE, MSE)
7. Visualization of Results

## 📈 Model Performance
- R2 Score: 0.84
- Mean Absolute Error: ~1.21
- Mean Squared Error: ~3.48

## 🎯 Conclusion
The model successfully predicts car prices with good accuracy.
This project demonstrates basic machine learning workflow and regression modeling.
